# StudyFlow
A responsive study task manager designed to help students organize tasks, deadlines, priorities, and track their academic progress.

## About the Project
StudyFlow is a frontend web application built around a simple idea, making academic task management clear and easy to use.
Instead of keeping assignments and deadlines scattered across different places, StudyFlow provides a single dashboard where students can add tasks, organize them by subject and priority, assign deadlines, track completed work, and monitor their overall progress.

## Features
* Add new study tasks
* Organize tasks by subject
* Set High, Medium, or Low priority
* Assign deadlines
* Mark tasks as completed
* Delete tasks
* Filter between All, Pending, and Completed tasks
* Track total tasks
* Track completed tasks
* Track high-priority tasks
* View overall study progress
* Responsive layout for different screen sizes

## Built With
* HTML5
* CSS3
* JavaScript
* DOM Manipulation
* Responsive CSS

## How It Works
1. Enter the task name and subject.
2. Select a priority level.
3. Choose a deadline.
4. Add the task to the dashboard.
5. Mark tasks as completed or delete them when needed.
6. Use the filters to view all, pending, or completed tasks.
7. Monitor your progress through the dashboard statistics.
